# Hyper-Othello

Hyper-Othello is a 3D take on the classic Othello/Reversi board game. Play on a cubic board (4×4×4 or 6×6×6), rotate the scene to inspect moves, and challenge another player or an AI opponent.

## Features

- 3D board visualization with rotatable camera
- Supports 4×4×4 and 6×6×6 game sizes
- Player vs Player and Player vs AI modes
- Slice viewer to inspect layers and cross-sections
- Real-time score tracking and reset controls

## Tech Stack

- React 19 + TypeScript
- Vite 7
- Three.js via React Three Fiber/Drei
- Zustand for state management
- Tailwind CSS styling

## Getting Started

```bash
npm install
npm run dev
```

Then open the local Vite dev server URL (typically http://localhost:5173).

## Scripts

- `npm run dev` - start the development server
- `npm run build` - build the production bundle
- `npm run preview` - preview the production build
- `npm run lint` - run ESLint
